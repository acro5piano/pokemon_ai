SECTION 01

何を試した？

タイプ相性が「じゃんけん」のようにつながる3体で、AIに正解を教えず、自分との対戦だけで作戦を発見させました。

実験を小さくするルール

3
お互い同じ3体

サイドン・スターミー・サンダー。チーム差はありません。

5
選べる行動は5つ

技2つ、または3体のどれかへ交代。できない行動は除外します。

19
AIが見る数字は19個

各ポケモンのHP・生存・場にいるか、そして交代フェーズか。

簡略化：技は必ず当たる。急所・状態異常・PPはなし。ただしダメージの乱数は残すので、毎試合同じ結果にはなりません。
SECTION 02

AIはどう学んだ？

DQNは、盤面ごとに「この行動は将来どれくらい得か」という予想点（Q値）を出す仕組みです。

STEP 01状況を見る

6体のHPや、今だれが場にいるかを19個の数字に変換。

STEP 02行動を選ぶ

高得点の手を基本に、序盤はわざとランダムにも動く。

STEP 03対戦を進める

交代を先に処理し、その後は素早いポケモンから攻撃。

STEP 04答え合わせ

勝ち +1、負け −1。HP差が良くなったことにも少し点を与える。

STEP 05過去から復習

最大5万件の経験から64件を抜き出し、予想点を修正。

例

テスト勉強にたとえると： 1問ずつ順番に覚えるのではなく、昔まちがえた問題も混ぜて解き直すのが「リプレイバッファ」。少し前の自分の解答を模範にして、採点が毎回ぶれすぎないようにするのが「ターゲットネットワーク」です。

agents.py — 予想点の更新

# 今すぐの得点 + 将来もっとも良い手の予想
answer = reward + gamma * best_next

# 選んだ行動だけ「正解」に近づける
targets[rows, actions] = answer
model.partial_fit(states, targets)

train.py — 過去の自分とも戦う

# 70%は保存しておいた過去AIと対戦
if pool and rng.random() < 0.7:
    opponent = rng.choice(pool)

# 古い作戦も残るよう、ランダムに入れ替える
pool[rng.randrange(len(pool))] = snapshot

SECTION 04

結局、どういう戦略が強い？

ログと勝率から見える答えは「大技を連打」ではありません。相性を読み、相手のクセを利用し、過去の作戦も忘れないことです。

BATTLE

不利なら、攻撃より交代

スターミー→サイドン→サンダー→スターミーの弱点ループがあります。欲張りAIは自分から交代しないので、有利な1体をぶつける作戦が特に効きます。

水 → サイドン
岩 → サンダー
電気 → スターミー
DEFENSE

「0ダメージ」を作る

サイドンは電気技を無効、サンダーは地面技を無効にします。ダメージ倍率を上げるだけでなく、相手の主力技を空振りさせる交代はとても強力です。

サンダーの電気技 → サイドン：0
サイドンの地面技 → サンダー：0
TRAINING

昔の自分を忘れない

今の自分だけと戦うと、3すくみの作戦をぐるぐる追いかけます。100試合ごとのAIを最大20体保存し、70%の確率で対戦する「リーグ」が、偏りを抑えます。

強い学習相手： 最新1体だけではなく、いろいろな時期の自分。

⚠ 勝率のギザギザも、大切な結果

欲張りAIへの勝率は、1,750試合で92% → 2,500試合で33% → 3,000試合で87.5% → 3,500試合で38% → 最後に99.5%。損失（予想のズレ）が小さくなっても、必ず勝率が上がり続けるわけではありません。3すくみでは「今の相手に刺さる作戦」へ寄りすぎると、別の作戦に弱くなるからです。

SECTION 05

数字を読むときの注意

この実験は成功ですが、「どんなポケモン対戦でも99.5%勝てる」という意味ではありません。

評価相手は2種類だけ

ランダムAIと、最大ダメージだけを見る欲張りAIです。人間のように先を読んで交代する新しい相手には、別途テストが必要です。

実験は seed=0 の1回

学習にもダメージにも乱数があります。結論を確かにするには、種を変えて複数回実験し、平均とばらつきを比べます。

最終ログにも無駄な手がある

4,000試合時の自己対戦では、効かない「じしん」をサンダーへ何度も選ぶ場面があります。高い勝率でも、作戦が完全とは限りません。

最高点の保存は正しい

途中で性能が下がるため、評価平均が更新された時だけ dqn-best.pkl を保存する設計は重要です。今回は最後が最高でした。

次にやると、もっと確かな実験になる

  1. seedを5つ以上に増やし、平均勝率と誤差を出す。
  2. リーグなし・ありを同じ条件で比べ、効果を数字で測る。
  3. 最新モデル同士の総当たりで、特定相手への対策だけになっていないか調べる。
